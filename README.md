# RESONANCE — The Balance of Worlds

A mobile-first 16-bit musical action platformer. The hooded bassist restores harmony across five soundscapes using resonant bass waves, rhythm puzzles, and guardian battles.

## Run locally

Open `index.html` in a modern browser. No build step or external runtime dependencies are required.

## Render deployment

This repository includes `render.yaml` for a Render Static Site. Connect the repository in Render and create the Blueprint; Render will publish the repository root. The game uses Canvas 2D and Web Audio and supports touchscreen controls.

## Controls

- Move: A/D or arrow keys; touch left/right
- Jump: Space or touch Jump
- Dash: Shift or touch Dash
- Choose notes: 1/2/3 or the C/E/G buttons
- Strum: K or touch Strum after matching the guardian's three-note phrase

Progress is saved locally in the browser.
